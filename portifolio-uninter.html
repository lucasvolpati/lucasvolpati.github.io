Sistemas que Construí

001

Plataforma de conversação assíncrona

Em Desenvolvimento

SaaS para profissionais autônomos realizarem sessões de texto assíncronas com seus clientes. Janelas de agendamento semanais, modelo de resposta em 24 horas, gravação de áudio e trilha de conteúdo integrada.

Decisões de Arquitetura

  • Mapa de conversação é o modelo central do sistema — cada mensagem tem um timestamp, uma referência ao cliente e à sessão, e um status de resposta. Isso mantém o histórico de cada conversa em ordem cronológica, preserva o contexto de cada conversa.
  • Gravadção de áudio com botão de "pressione e solte" — sem dependência com bibliotecas de terceiros, controle total no armazenamento de dados BLOB

Estrutura do produto

  • Módulo Chat Assíoncrono
  • ódulo Dashboard — view consolidada de todos os clientes ativos

002

Sistema de gerenciamento para auto mecânicas

Entregue

Sistema de gerenciamento para uma oficina de reparo automotivo. Projeto desenvolvido para otimizar o fluxo de trabalho e aumentar a eficiência na gestão dos serviços.

Estrutura do produto

  • Foi utilizado o Laravel starter kit com Vue.js e Inertia para desenvolvimento rápido e validação
  • Continuous Delivery com GitHub Actions, sim! Esse projeto já está em produção desde abril de 2025, rodando em uma VM mínima no Google Cloud.
  • E no Google Cloud eu usei uma configuração basica para economizar custos do cliente, como balanceamento de CPU de acordo com o uso, e rotinas de parada da VM.

Problema → Solução

  • Problema: Eles precisavam de um sistema para gerar ordens de serviço, para organizar em categorias de aprovado/rejeitado/pago, e também poder gerar um PDF para enviar aos clientes para aprovação.
  • Solução: Um sistema-web com um módulo de ordens de serviço onde eles podem descrever todos os serviços e itens com custos e preços para definir o orçamento final, além de um gerador de PDF com um botão para compartilhar com os clientes, tudo em uma única tela.
  • Resultado: visibilidade em tempo real sem mudar o fluxo de trabalho existente
